Employee Retention Prediction Project

Academic Project

This project focuses on analyzing a human resources dataset to understand the factors influencing employee retention and to build a predictive model to identify employees at risk of leaving the company. Employee turnover can be costly for organizations, and proactively identifying potential departures can enable timely interventions.

Key Results:

• Satisfaction Level: Employees who left had significantly lower average satisfaction levels.
• Promotions: Lack of promotion in the last 5 years was strongly associated with employees leaving.
• Department: 'HR' and 'Accounting' departments showed higher turnover rates, while 'Management' and 'RandD' had lower rates.

Technologies Used:

Pandas Tensor Flow Plotly

Customer Churn Analysis Project

Academic Project

This project involved an exploratory data analysis (EDA) of an online retail customer dataset to understand customer behavior and identify potential factors contributing to customer churn. The primary goal was to gain insights that could inform strategies for customer retention.

Key Results:

• There is a very weak positive linear relationship between Years_as_Customer and Total_Spend, and Num_of_Purchases and Total_Spend, suggesting these factors are not strong predictors of overall spend.
• The churn rate varies slightly by gender, with 'Other' gender having a slightly higher churn rate.
• Email opt-in status shows a negligible difference in churn rates (52.55% for opt-in vs. 52.65% for non-opt-in), indicating it is not a significant factor in churn for this dataset.

Technologies Used:

NumPy MatplotLib Seaborn

Titanic Dataset EDA

Academic Project

This project focuses on performing Exploratory Data Analysis (EDA) on the Titanic dataset using Python and a Kaggle Notebook. The analysis aims to understand the structure, quality, and patterns within the data, with a particular emphasis on factors influencing passenger survival. The project was completed as part of a data analytics training assignment to strengthen practical skills in data exploration, visualization, and analytical reasoning using real-world data.

Key Results:

• Bivariate analysis to examine relationships between survival and key variables such as gender, age, class, and fare.
• Multivariate analysis to uncover interaction effects between multiple features.
• Conducted detailed target variable analysis on survival outcomes.

Technologies Used:

Python Scikit-Learn Pandas
